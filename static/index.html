Theme Forge Packages

Official, signed, reproducible self-distribution channels for the Theme Forge product family:

Stellar Burst 0.6.1 Stellar Loom 0.4.0 Solar Sail 0.2.1 Nebular Fusion 0.6.1

Channel 1: Nix Flake

Install directly from GitHub via Nix Flakes on Linux (x86_64, aarch64) or macOS (Apple Silicon / Intel):

# Install CLI tools
nix profile install github:Knowledge-Forge-AI/theme-forge-packages#theme-forge-stellar-burst
nix profile install github:Knowledge-Forge-AI/theme-forge-packages#theme-forge-stellar-loom
nix profile install github:Knowledge-Forge-AI/theme-forge-packages#theme-forge-solar-sail

# Install Nebular Fusion GUI workbench
nix profile install github:Knowledge-Forge-AI/theme-forge-packages#theme-forge-nebular-fusion

# Run without installation
nix run github:Knowledge-Forge-AI/theme-forge-packages#tfnf -- --help

Upgrade: nix profile upgrade '.*'

Uninstall: nix profile remove theme-forge-stellar-burst

Channel 2: Pacman (Arch Linux)

Import and verify the distribution OpenPGP signing key, then configure the custom repository in /etc/pacman.conf:

# 1. Download and import repository signing key
curl -sSfL -o /tmp/kfa-packages.asc https://knowledge-forge-ai.github.io/theme-forge-packages/keys/knowledge-forge-ai-packages.asc
sudo pacman-key --add /tmp/kfa-packages.asc
FPR=$(gpg --show-keys --with-colons /tmp/kfa-packages.asc | awk -F: '/^fpr/{print $10; exit}')
sudo pacman-key --lsign-key "$FPR"
rm /tmp/kfa-packages.asc

# 2. Append repository block to /etc/pacman.conf
sudo tee -a /etc/pacman.conf << 'EOF'

[knowledge-forge-ai]
SigLevel = Required DatabaseRequired TrustedOnly
Server = https://knowledge-forge-ai.github.io/theme-forge-packages/arch/x86_64
EOF

# 3. Synchronize and install
sudo pacman -Sy
sudo pacman -S theme-forge-stellar-burst theme-forge-stellar-loom theme-forge-solar-sail theme-forge-nebular-fusion

Upgrade: sudo pacman -Syu

Uninstall: sudo pacman -R theme-forge-stellar-burst

Channel 3: DNF / RPM (Fedora Linux)

Add the signed repository configuration and install packages using native DNF:

# 1. Install repository definition
sudo tee /etc/yum.repos.d/knowledge-forge-ai.repo << 'EOF'
[knowledge-forge-ai]
name=Theme Forge Packages
baseurl=https://knowledge-forge-ai.github.io/theme-forge-packages/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://knowledge-forge-ai.github.io/theme-forge-packages/keys/knowledge-forge-ai-packages.asc
EOF

# 2. Install packages
sudo dnf install theme-forge-stellar-burst theme-forge-stellar-loom theme-forge-solar-sail theme-forge-nebular-fusion

Upgrade: sudo dnf upgrade

Uninstall: sudo dnf remove theme-forge-stellar-burst
